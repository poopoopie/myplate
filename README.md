# Longevity 飲食清單

## 1. 目的

- 最佳化長期健康、延緩老化、預防疾病；有合理科學訊號即可，不要求直接延壽證據。(更傾向自己做 N=1 實驗驗證)
- 以多樣化原型食物攝取不同營養素、纖維與植物活性成分。
- 盡量減少有害物質的長期累積。

## 2. 新食材篩選條件

- **健康價值**：特殊營養素、現有飲食缺少的成分、有益人體的研究證據；避免高度重複。
- **安全性**：重金屬（尤其 Cd、Pb）、草酸、農藥、天然毒素、糖／果糖、鐵、抗營養因子、胃部刺激等。
- **採購**：台灣買得到、優先有機、來源可靠、價格與運費／免運條件合理；季節性可接受。國外採購須耐保存（>2週）、單次完稅價格 ≤ NT$2,000，留意半年6次免稅限制。
- **料理**：優先原型、少加工；簡單清洗、同鍋蒸熟直接吃，不需複雜處理。
- **研究方法**：人體證據優先，機制／動物研究也可參考；有害物質盡量使用同食材實測數據。
- **重評規則**：已淘汰食材只有出現新證據、新商品或污染資料時才重新評估。

## 3. 飲食清單（包含已接受食材）

### 蔬菜 (全有機)

- 全聯常見有機蔬菜：以十字花科為主（白菜、小松菜、羽衣甘藍等），其他如苦瓜、小黃瓜、櫛瓜、秋葵、胡蘿蔔、甜菜根、紫茄、青椒、山茼蒿、萵苣、A菜、等。
- 紫高麗菜：花青素。
- 朝鮮薊：Inulin、多酚；季節性。
- 綠蘆筍：低草酸；季節性。
- 紫心地瓜：花青素；偶爾取代其他澱粉。
- 番茄、酪梨：季節性。
- 大蒜、洋蔥：少量，避免胃部刺激。
- 桑葉乾：DNJ。

### 蕈菇類 (全有機)

- 金針菇、鴻喜菇、杏鮑菇、秀珍菇、黑蠔菇、香菇。
- 銀耳、黑木耳、川耳。
- 猴頭菇：Hericenones、Erinacines。
- 雨來菇

### 豆類、穀類 (全有機)

- 黃豆、自製納豆、紅扁豆。
- 小米、三色藜麥、紅薏仁。

### 堅果、種子、藻類

- 核桃、夏威夷果、胡桃、開心果、南瓜子、巴西堅果。
- 野生愛玉籽（連殼）。
- Spirulina、Chlorella。

### 其他

- EVOO。
- Kefir、乾酪、可可。
- 薑黃、黑胡椒、迷迭香、黑種草籽（Nigella sativa; Thymoquinone）、余甘子（Amla; 降 LDL & PCSK9）。
- 洋甘菊：Apigenin
- 乾橙皮（Orange peel）

## 4. 已評估，不再主動推薦

- 生薑：Pb 偏高。
- 黑豆：Cd 來源疑慮；改黃豆。
- 黑米、糙米：稻米重金屬。
- 韃靼蕎麥：Cd 累積疑慮。
- 洋車前子殼：Pb 污染疑慮。
- 西洋菜：重金屬、寄生蟲。
- 繡球菇：As 資料不確定、有機來源不足。
- 球莖甘藍：Cd 疑慮、特殊價值低。

- 洛神花：高草酸、酸度高。
- 紅鳳菜：高草酸。
- 牛蒡：草酸偏高。
- 奇亞籽：草酸、營養重複。
- 亞麻籽：Cd、需研磨、氰苷疑慮。
- 羅勒籽：Estragole 疑慮。
- 蝶豆花：Cyclotides 安全性不明。
- 竹筍：氰苷、處理麻煩。

- 燕麥片：升糖快。
- 燕麥仁、燕麥麩：麥類 Lectins 疑慮、碳水負擔。
- 小麥：Lectins／腸道疑慮。
- 一般蕎麥：過敏疑慮。
- 雞蛋：黃豆可提供類似營養、養殖環境、LDL 顧慮。
- 天貝：與黃豆／納豆重複、有機來源難找。
- 菊芋：糖／果糖、處理麻煩、CP 低。
- 雪蓮果：果糖、FOS 儲存損失。
- 苦瓜／山苦瓜：草酸、額外效益不明。
- 青花椰菜苗：與既有十字花科重疊、生芽菜食安。
- 紫蘆筍：花青素低、價格高。
- 紫蘇：鐵較高、免運條件高。
- 蒟蒻：多以加工後(粉狀)販售。
- 刺山柑：多以加工後販售(醃製)、缺有機來源。
- 咖啡：Cafestol、製作麻煩。
- 有機抹茶：價格高。
- 紅麴：毒素風險。
- 胡蘆巴籽：刺激 insulin。
- 野櫻莓乾（Aronia）：糖分高、花青素單調、表現輸藍莓。
- 歐洲野生越橘乾（Bilberry）：糖分高、貴、表現輸藍莓。
- 黑醋栗乾（Blackcurrant）：糖分高、貴、表現輸藍莓。
- 黑樹莓乾（Black raspberry）：糖分高、貴、表現輸藍莓。
- 綠國寶茶（Green Rooibos）：PA 風險、Aspalathin 表現不強
- 黑蒜：沒有機、和生大蒜成只差成分比例不同(果糖更高)。
